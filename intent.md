# Feedback Sentiment Classifier Agent

AI agent that classifies customer feedback into positive, negative, or neutral sentiments with confidence scores and reasoning.

## Business challenge

Classify incoming customer feedback text into positive, negative, or neutral sentiment categories, providing a confidence score and a brief reasoning explanation for each classification. The agent must achieve ≥90% accuracy and respond in under 1 second.

## Key Milestones

1. **Input received** — Agent receives raw feedback text via A2A protocol request.
2. **Sentiment classified** — Agent returns a sentiment label (positive / negative / neutral) with a confidence score.
3. **Reasoning provided** — Agent returns a brief natural-language explanation for the classification decision.
4. **Response delivered** — Complete structured response returned to caller within < 1 second.

### Key findings

- No standard SAP product provides an out-of-box sentiment classifier with confidence scores and reasoning; a custom AI agent is required.
- SAP AI Core provides the LLM runtime; a lightweight model (e.g. GPT-4o-mini or equivalent) is recommended to stay under the 1-second SLA.
- The A2A protocol enables the agent to be called by other agents or applications in the SAP ecosystem.
- Service Ticket Intelligence offers text classification for service tickets but lacks confidence scores and reasoning output.
- The agent will expose a clean, structured JSON response with `sentiment`, `confidence`, and `reasoning` fields.

## Recommendations

### Sentiment Classification AI Agent

#### Executive Summary

Pro-code Python AI agent classifying feedback with confidence & reasoning.

#### Recommended Solution

A Python-based AI agent (A2A protocol) hosted on SAP AI Core. The agent accepts feedback text as input, calls an LLM to classify sentiment (positive / negative / neutral), and returns a structured JSON response containing the sentiment label, a 0–1 confidence score, and a brief natural-language reasoning explanation. The agent is instrumented with OpenTelemetry for observability.
